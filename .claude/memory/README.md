# TPM notes

The owner's standing rules and lessons learned, one fact per file. `ready-pr-checklist.md` is the one exception: it is a single checklist with several steps. The TPM reads all of these at the start of every session. To change a rule, the owner says so and the TPM updates the file through a PR the owner merges.
